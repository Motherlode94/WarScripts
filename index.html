Démarrage rapide

Clone le dépôt, utilise Node.js 22 et lance les tests. Le lexer est utilisable sans dépendances externes.

git clone https://github.com/Motherlode94/WarScripts.git
cd WarScripts
npm test
import { tokenize } from './src/lexer.js';
console.log(tokenize('float speed = 5.0;'));

Le lexer analyse la forme du texte : il ne valide pas la grammaire, ne résout pas les types et n'exécute pas les fonctions.

API et diagnostics
tokenize(source: string)
  → { kind, value, line, column }[]
Les positions commencent à 1. Le résultat conserve le texte brut des tokens. Une erreur lexicale déclenche SyntaxError ; un argument non textuel déclenche TypeError.
Pourquoi un code invalide peut produire des tokens ?
Le parser n'est pas encore implémenté. L'analyse lexicale ne vérifie pas les déclarations, les parenthèses ni la sémantique.
Compatibilité avec C#
La syntaxe s'en inspire. Ce n'est pas un compilateur C# et aucune compatibilité complète n'est revendiquée.
